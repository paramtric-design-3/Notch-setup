Add these lines to %USERPROFILE%\.claude\settings.json. If the file already has a "hooks" block, merge them into it.


    
Copied

    
When Claude asks for permission, the notch opens with the full command. Allow becomes active once you've seen all of it. Shortcuts: Ctrl+Alt+Y allow, Ctrl+Alt+N deny. If you don't answer within 110 seconds, Claude Code asks in the terminal as usual.

  


  

    
Updates

    
Version …

    
FJBC Notch checks for a new version every 5 minutes and whenever your PC wakes up. It downloads updates in the background and installs them by itself once you've left the PC alone for a minute (it restarts in a few seconds).

  


  

    
Privacy

    
Nothing leaves this PC except weather requests (Open-Meteo), lyrics lookups (LRCLIB), album covers when the player doesn't provide one (iTunes Search), update checks (GitHub) and your calendar link if you add one. No accounts, no analytics.
